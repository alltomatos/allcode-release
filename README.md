# AllCode release feed

Repositório público usado apenas para distribuir o AllCode Desktop e o feed de atualizações.

- Instaladores: aba Releases.
- Metadados do updater: latest.yml, latest-mac.yml, latest-linux.yml.
- Changelog consumido pelo app: changelog.json na branch main.

O código-fonte vive no repositório privado alltomatos/allcode.
